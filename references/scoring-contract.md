# Code Edition 评分协议

所有数值都由代码从四柱事实生成，状态统一为 `computed` 语义；没有人工估分、上下限传播或模型补分。
输入不支持某层级时直接不生成依赖指标。

## 单盘指标

| 指标 | 代码含义 | 边界 |
| --- | --- | --- |
| R/D/Y-DSS | 当前完整层的承载/压力比 | 非负比值 |
| R/D/Y-DFP | 五行边际收益 | 每项 -3 至 +3 |
| NBS | 原局承载、能量分布、调候、路线与稳定性 | 0–100 |
| DLS | 大运相对原局的承载改善、喜忌匹配与互动净效用 | 0–100 |
| YDS | 流年相对 R+D 的承载变化、匹配与年度互动 | 0–100 |
| DSS 分 | DSS 距离目标承载中心的固定映射 | 0–100 |
| DFP 分 | 当前喜忌谱的强度与可辨识度 | 0–100 |
| SCS | R、D、Y 同向支持或互相拆台 | 0–100 |
| VP | 去重后的结构波动惩罚 | 0–25 |
| AFS | 年度结构顺逆 | 0–100 |
| EAI | 年度事件激活强度 | 0–100 |
| EFM | 事业、财务、关系、健康、学习、迁移激活 | 各 0–100 |

年度总分仅在 R+D+Y 完整时产生：

`AFS = clamp(0.20NBS + 0.20DLS + 0.20YDS + 0.15DSS分 + 0.15DFP分 + 0.10SCS - VP)`

EAI 不进入 AFS。AFS 判断顺逆，EAI 判断强度，EFM 判断领域。

## 合婚指标

| 指标 | 代码含义 | 边界 |
| --- | --- | --- |
| IMS-A / IMS-B | 各自关系承载、夫妻宫、伴侣星、路线与边界 | 0–100 |
| IMS | 两人均值减确定性短板惩罚 | 0–100 |
| BCS | 静态双盘结构诊断 | 0–100 |
| RFS | 双向喜忌与可持续供给适配 | 0–100 |
| MPS | 夫妻宫、伴侣星、角色与保护 | 0–100 |
| CRS | 双向生克路线与通关 | 0–100 |
| CHS fit | 双向调候互补 | 0–100 |
| HOI quality | 跨盘合类互动的净质量 | 0–100 |
| CFS | 静态关系顺逆 | 0–100 |
| DCS / YCS | 十年阶段 / 年度关系适配 | 0–100 |
| R-SCS | 双方与运岁协同 | 0–100 |
| RVP | 静态或动态关系波动 | 0–25 |
| R-AFS | 关系年度顺逆 | 0–100 |
| RAI | 关系事件激活强度 | 0–100 |

短板惩罚以 `min(IMS-A, IMS-B)` 与两人差值确定：最低分低于 55 或差值至少 20 扣 3；最低分低于 45
或差值至少 30 扣 6；最低分低于 30 或差值至少 40 扣 10；否则不扣。

静态总分：

`CFS = clamp(0.20IMS + 0.20RFS + 0.20MPS + 0.15CRS + 0.10CHS_fit + 0.10HOI_quality + 0.05SSF - RVP_static)`

BCS 必须展示，但原公式未给它权重，所以不进入 CFS。SSF 固定为 50，不允许模型追加神煞分。

年度关系总分：

`R-AFS = clamp(0.30CFS + 0.20DCS + 0.20YCS + 0.15CRS_Y + 0.15R-SCS - RVP_dynamic)`

CFS 只减静态 RVP；R-AFS 只减包含 D/Y 新节点的动态 RVP。同一静态冲害不会原样扣两次。RAI 不进入
R-AFS。

## 分档

AFS、CFS、R-AFS 共用左闭右开分档：

| 分数 | 标签 |
| --- | --- |
| 0–<30 | 大忌/高风险阶段 |
| 30–<45 | 阻滞明显 |
| 45–<55 | 中平偏险 |
| 55–<70 | 中上 |
| 70–<85 | 顺势 |
| 85–100 | 大顺/高度顺势 |

EAI、RAI：0–<30 平淡，30–<50 小变化，50–<70 明显变化，70–<85 大变化，85–100 强烈变局。

## 证据与去重

每条互动有稳定 `id` 与 `dedupe_group`。同组在同一指标中使用“最强一条 + 其余 25%”；互动方向由
当前层 DFP 判断，不用“见合加分、见冲扣分”。关系波动另保留冲刑害破的运动成本，因此可能出现“冲开
忌神但关系仍需协调”。

报告可引用这些字段：`rule_id`、`members`、`sources`、`positions`、`result_element`、`net_effect`、
`dedupe_group`。不得另造未出现在代码输出中的证据分。
