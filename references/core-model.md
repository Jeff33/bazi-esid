# ESID 2.5 Code Edition 核心规则

本版把原方法稿未公开的底层量尺冻结为版本化代码。它是新的确定性实现，不声称这些补齐常量原本就写在
PDF 中。以后任何影响结果的常量或算法变更都必须升引擎版本并改变哈希，不能在答复中临时改口径。

## 权威顺序

1. 用户确认的四柱、大运、流年是输入事实。
2. `scripts/esid_engine/constants.py` 是干支表、权重、互动表与总分权重的权威源。
3. `facts.py` 是十神、藏干、来源节点和互动事实的权威实现。
4. `scoring.py` 与 `compatibility.py` 是所有组件与总分的权威实现。
5. 参考文档解释代码，不得用文档文字覆盖实际代码输出。

语言模型不能新增证据、修改分数或选择另一套参数。若发现代码与文档不一致，应先修复、升版、测试，再
继续正式分析。

## R、D、Y 全量重算

固定来源能量权重：R=`1.00`、D=`0.70`、Y=`0.45`。R+D 与 R+D+Y 都从该层全部节点重新提取能量与
互动；不把上一层结果增量相加。原局月支始终是季节锚点，大运和流年只能改造结构，不能替换月令。

稳定节点 ID 示例：

- `A_R.month.stem`
- `A_R.month.branch.hidden.0`
- `A_D.luck.branch`
- `A_Y.annual.stem`

合婚使用 A/B 来源；共享流年只在关系系统中建立一个合成 Y 节点，防止同一流年被复制成两位关系参与者。

## 基础能量 E

地支只通过藏干计入，避免把支的主五行重复计算。公式为：

`节点能量 = 来源权重 × 位置权重 × 藏干份额 × 月令系数 × 柱体/状态修正`

冻结内容包括：

- 十干阴阳五行与十二支藏干比例。
- 年、月、日、时、大运、流年的干支位置权重。
- 十二月支对五行的季节系数。
- 同气、支生干、干生支、盖头、截脚的一柱修正。
- 透干、动态根、冲根、合局成势的固定修正。

日干是评价中心，干层权重为 0，不作为普通比劫再计一次。时柱未知时直接缺少对应节点，不生成虚拟时柱。

## 互动事实

代码识别：天干五合/四冲、六合、六冲、六害、六破、子卯刑、寅巳申刑、丑未戌刑、辰午酉亥自刑、
三合、半合、三会与四库引动。每条事实保存成员节点、来源、位置、结果五行、强度和稳定证据 ID。

合不自动为吉，冲不自动为凶。评分时先根据当前层 DFP 判断被合、被冲或转化后的净效用。同一事件经
HOI、TDI、RPS 等多个概念被描述时，使用 `dedupe_group` 汇总：最强证据全计，其余同组只计 25%，
避免机械叠加。

本版不实现空亡、暗合、十二长生和独立神煞加分，因为原稿没有给出完整统一量表。未实现项目不能由模型
在代码外追加；SSF 在合婚公式中固定为中性 50。

## DSS 与 DFP

DSS 是承载/压力比，不是吉凶：

- 承载：比劫与印。
- 压力：食伤、财、官杀，使用代码中固定压力系数。
- 动态印比根有根气放大；若 Y 直接攻击 D 的药根，按固定比例折损。
- DSS 分使用固定对数距离映射，目标中心为 1；这只是 Code Edition 的适配量尺。

区间端点：`<0.65` 极弱、`[0.65,0.80)` 明显偏弱、`[0.80,0.95)` 偏弱、
`[0.95,1.10)` 中和、`[1.10,1.30)` 偏旺、`>=1.30` 旺。

DFP 根据 DSS 所处承载状态生成扶抑基础值，再加入固定调候、过旺饱和与根受冲修正；五行值限制在
`[-3,+3]` 并以 0.5 为步长。每层重新计算，不能沿用 R 层标签。

## 确定性与边界

- 代码不读取网络、当前日期、随机数或未声明环境状态。
- 同一规范化输入、规则哈希、实现哈希必须得到逐字节相同的规范 payload。
- 代码输出是 ESID 内部指标，不是科学概率、医学诊断、法律结论或投资保证。
- 传统术数解释只能帮助复盘；重大现实决定仍以事实、双方意愿与专业意见为准。
